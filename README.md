# 🎤 DevConf 2026 — Code. Connect. Create.

**DevConf 2026** is a modern, dark-themed developer conference landing page built with semantic **HTML5** and **CSS3**. Designed from a Figma specification as part of Batch 14 Assignment 01 (`B14-A01`), this single-page web interface brings together event overviews, speaker lineups, conference tracks, tiered ticket pricing, and grand-prize details in a clean, cohesive layout.

🔗 **Live Preview:** [https://rubaeitferdous.github.io/B14-A01-DevConf-2026-rubaeitferdous/](https://rubaeitferdous.github.io/B14-A01-DevConf-2026-rubaeitferdous/)  
📦 **Repository:** [github.com/rubaeitferdous/B14-A01-DevConf-2026-rubaeitferdous](https://github.com/rubaeitferdous/B14-A01-DevConf-2026-rubaeitferdous)

## ✨ Key Features & Sections

- **Navigation & Hero Banner:** Clean top navigation bar (`Speakers`, `Schedule`, `Tracks`, `Venue`, `Blog`) paired with a high-contrast, image-backed hero section featuring the **"Code. Connect. Create."** headline and primary registration call-to-action buttons.
- **Meet the Speakers:** Structured CSS Grid layout showcasing speaker profile cards with portraits, names, designations/companies, and specialized domain track badges (**AI/ML**, **Cloud & DevOps**, **Frontend**, and **Security**).
- **Custom Event Highlight Section:** Dedicated section extending the core conference experience while maintaining consistent typography, spacing, and visual hierarchy.
- **Ticket Pricing Tiers:** Three-column pricing comparison (**Standard**, **Pro**, and **Team** passes) with the **Pro** tier visually emphasized as the featured option, complete with itemized benefits and registration CTAs.
- **The Grand Slam ($15,000 Grand Prize):** Spotlight banner highlighting the **$15,000** total award pool alongside quick access to official participation rules.
- **Branded Footer:** Includes DevConf 2026 branding, quick navigation links, social media icons, and copyright metadata.
